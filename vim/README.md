# vim

## update new vim on ubuntu

1. add vim PPA on ubuntu, `sudo add-apt-repository ppa:jonathonf/vim`
2. update PPA software package, `sudo apt update`
3. upgrade vim, `sudo apt list --upgradable`

## install vim-plug
`curl -fLo ~/.vim/autoload/plug.vim --create-dirs https://raw.githubusercontent.com/junegunn/vim-plug/master/plug.vim`
